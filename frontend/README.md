# Perspxtv Frontend

Vue.js UI for **Perspxtv** — TikTok Shop trend discovery, evaluation, and template workflows, plus the agent chat surface.

## Stack

- Vue 3 + Vite + Tailwind
- `@videodb/chat-vue` and `@videodb/player-vue` (runtime dependencies; no VideoDB product branding in this UI)

## Routes

- `/` — TikTok Shop Trend Lab
- `/chat` — Perspxtv agent chat

## Development

```bash
npm install
npm run dev
npm run test
```
